# Study Planner (beta)

SillyTavern 확장. 좋아하는 캐릭터와 채팅하면서 공부 시간을 기록하고, 계획을 같이 짜고, 기록을 캐릭터가 자연스럽게 알아보게 해 줘요.

> 캐릭터의 성격과 말투는 **봇카드**가 정해요. 이 확장은 성격을 정하지 않고, 공부 기록을 참고 정보로만 전달해요.

## 설치

SillyTavern → Extensions → **Install extension** → 아래 주소 입력

```
https://github.com/DenBzs/StudyPlanner
```

설치 후 새로고침하면 마법봉(Extensions) 메뉴에 **Study Planner**가 생겨요.

## 기능

**오늘**
- 과목을 고르고 공부 시작 / 종료
- 집중 모드: 검은 화면에 캐릭터 프로필과 타이머만 표시, 화면 꺼짐 방지(Wake Lock)
- 오늘 총 공부 시간, 과목별 시간, 오늘 할 일 체크
- 오늘 기록을 채팅 입력창에 넣거나 바로 전송 (하고 싶은 말을 함께 보낼 수 있어요)

**계획**
- 기간은 자유: 하루, 내일, 일주일, 한 달, 몇 달, 아무 날짜 범위
- 직접 만들고 수정 / 삭제, 상위 계획 연결
- **대화에서 정리**: 최근 대화를 읽고 계획을 JSON으로 뽑아 미리보기로 보여줘요. 고친 뒤 저장해요
- 같은 제목의 계획은 덮어쓰기로 갱신 (완료 체크는 유지)

**기록**
- 최근 7일 그래프, 연속 일수, 누적 시간
- 깜빡하고 안 눌렀을 때 직접 기록 추가 / 삭제

**설정**
- 프롬프트에 기록 넣기 on/off, 주입 깊이
- 초 단위 표시, 진행 중 표시 띠, 프로필 이미지 직접 지정
- 하루 시작 시각 (기본 04:00 — 새벽 공부는 전날로 묶여요)
- D-day, 과목 관리, 강조 색, 내보내기 / 가져오기

## 캐릭터에게 전달되는 내용

생성할 때마다 아래 같은 짧은 요약이 영어 시스템 메시지로 들어가요. "참고용이고 억지로 꺼내지 말 것"이라는 안내가 함께 들어가서, 일상 대화 중에는 공부 얘기를 강요하지 않아요.

- 오늘 공부 시간(과목별), 지금 공부 중인지
- 최근 7일 합계, 연속 일수
- D-day
- 오늘 / 내일 계획과 체크 상태

## 데이터

- 전역 설정(`extensionSettings`)에 저장돼서 캐릭터를 바꿔도 이어져요.
- 시간은 `지금 - 시작 시각`으로 계산해서 화면이 꺼지거나 탭이 느려져도 틀어지지 않아요.

## 알려진 제한 (beta)

- 일시정지 기능 없음 (끊고 다시 시작하면 돼요)
- 그룹 채팅에서는 캐릭터 프사 대신 아이콘이 나와요 (프로필 이미지 주소를 직접 지정하면 돼요)
- 대화로 계획을 "수정"하는 기능은 아직 없고, 직접 수정하거나 같은 제목으로 다시 정리하면 돼요
- 사용 중인 SillyTavern 버전에서 `setExtensionPrompt`가 없으면 프롬프트 주입만 꺼져요
